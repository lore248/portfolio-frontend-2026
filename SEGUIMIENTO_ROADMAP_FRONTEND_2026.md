# 12. REGLA FUNDAMENTAL PARA MODIFICACIONES FUTURAS


Durante la construcción del proyecto se utilizará siempre el siguiente método:


NO utilizar instrucciones como:

- Buscar esta línea.
- Añadir debajo de este bloque.
- Modificar solamente esta parte.
- Inserta este código en esta posición.


Motivo:

Evitar errores al modificar archivos grandes y mantener siempre una versión coherente del proyecto.


Método obligatorio:

Cuando haya que actualizar un archivo:

1. Abrir el archivo completo.
2. Vaciar el contenido existente.
3. Sustituir por el archivo completo actualizado.
4. Guardar.
5. Comprobar funcionamiento.


Aplicar esta norma a:

- index.html.
- css/style.css.
- js/app.js.
- Cualquier otro archivo del proyecto.
